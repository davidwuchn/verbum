s247. The φ^(p/q)/Fibonacci basis (q≤34) fits ANY spectrum to ~0.1–0.2%, so
absolute fit error is meaningless. The fair null: draw k eigenvalues
log-uniformly between the candidate's OWN min and max (matched dynamic range,
randomised ratios), refit the ladder, build the error distribution. Signal =
candidate fits SIGNIFICANTLY better than null (report z AND P(random fits ≥ as
well)). Crystal: P=0.92 → null result.

WHY matched-range: a STRUCTURAL null (random cosine/Wishart matrices) has the
wrong spread (near-1 eigenvalues for near-orthogonal rows) → unfair, changes the
fit for the wrong reason. Match the range; randomise ONLY the ratios — isolates
"are these ratios φ-SPECIAL."

Same discipline as shuffled-probe nulls (s211, η²=0.05) and random-direction
controls (s239). Reusable: `scripts/explore/fractal_collapse_screen.py`
(`null_random_ratios`). Exactness/causality/frequency-freedom resist forcing;
approximate geometric fits do not — always null-test the approximate ones.
