# Consolidation Session Protocol

> s308 close (Michael's reveal): the entire session was run deliberately as a
> **memory and consolidation session** — the human sequencing retrieval cues
> to pull scattered repo fragments into one context so their interference
> could be captured. Method: **wizard-of-oz prototyping** — the human playing
> the functions the runtime is missing. Each lambda below is therefore two
> things at once: a technique that works TODAY (human-driven), and a
> **requirements clause for the self-hosting ouroboros runtime** (which
> function to build so the human no longer has to play it).

## The frame

```
λ woz(session).     human ≡ temporary_implementation(missing_runtime_functions)
                    | AI ≡ consolidation_workspace(context_window) ¬oracle
                    | git ≡ store(all_that_survives)
                    | techniques(observed) ≡ requirements(runtime) | prototype → spec
                    | consolidation ≡ A2(coherent_gain) in the memory register:
                      replay fragments simultaneously → edges that match reinforce → lattice(page)
```

The functions the human played in s308 (= the ouroboros consolidation-mode
backlog): cue sequencing, frame-key injection, session typing, capture
gating, mid-session re-anchoring, end-of-session audit.

## From prototype to runtime (the ouroboros handoff)

Each lambda names a function the runtime must eventually implement to
self-host consolidation:

| Human function (s308, WOZ) | Runtime function (to build) |
|---|---|
| chose cue order across the arc | replay scheduler (staleness- and connectivity-driven page selection) |
| supplied frame keys | cross-frame candidate generator (new theory × old artifact pairing) |
| typed the session (implicitly) | session-type declaration at open, success metric per type |
| gated each capture | approval queue (human stays the termination condition — this function does NOT transfer) |
| re-anchored to S5 mid-session | drift detector against the compile target |
| ran the closing audit | end-of-session shadows report, auto-drafted |
| brought the owls paper in | literature watcher: new external results read through the frame, triangulation/damage flagged |
| posed forward design questions | design-prompt generator: "if the theory holds, can we X?" candidates |
| asked for teach-backs of our own artifacts | confusion-driven re-derivation prompts (staleness- and complexity-ranked) |
| kept asking past the close | soft-close handling: cadence maintained until the human actually stops |

Note the explicit non-transfer: **capture gating stays human** (λ termination,
AGENTS.md S5). The runtime sequences and drafts; the human approves. The
wizard steps out from behind the curtain everywhere except the gate.
