output is a discrete code. "Error-correcting step function" ≡ sign(W): the
step function digitizes the analog tally; error correction makes the
digitization safe.

Evidence (retrodictive — all measured, none pre-registered for THIS frame):
- **Two populations** (s309/310 sign-commitment-curve): confident core commits

  gradient traffic votes against itself; signal = the tiny net tally.

  weight = vote tally; sign = committed allele; magnitude = accumulated
  evidence before fixation.
