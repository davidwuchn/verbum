## The asset list (measured holdings)

1. **~600 KB skill wires** — facts baked into ternary LoRA deltas; retention
   1.0, install/uninstall bit-exact, two wires compose with zero measured
   interference (s303–s312).
2. **The write corridor** — KL-to-base anchor (weight 10) + host-CE budget +
   evidence-gated stop = install knowledge without host damage, with a
   certificate (TW5-style: host CE + real-competence + restore) (s315).
3. **The transit law** — facts act only from the tape; the licensing
   statement *format* is measured (classificatory subject-predicate; check
   reads class content, not statement form — deranged statements license the
   anti-class) (s315 §9/§11).
4. **The stethoscope** — 903-probe battery reads the routing register;
   9×9 crystal universal 11/11 models; type register discriminates training
   regime 7/11 (family-clean) (s303, s313–s314).
5. **Register-scoped reads** — what survives quantization (routing signs);
   where value content is legible (depth ≥0.6); halt/fire poles in the
   17×17 scheduler register (s304–s308, s227b).

## Tier 1 — buildable immediately (infra exists in-repo)

### 1. Recall-then-redeliver (runtime fix for the delivery failure)

The baked wire recalls (p=5e-4) but does not license; tape delivery
licenses (p=0.008). Compose them at runtime: query the model's own baked
fact in a recall frame ("A florb is a kind of …" → "animal"), append the
answer to context as a classificatory statement, proceed. Weights = cheap
storage, tape = delivery, two-line loop = the missing lifting mechanism.
Both halves measured; the composition is one afternoon on the existing
type_write/type_icl_tag harnesses. Architecture claim in miniature:
the model as its own retrieval database (self-RAG grounded in register
physics, not embedding similarity).

### 2. Skill cartridges (git-for-weights, live demo)

Bake N fact-packs as ~600 KB ternary cartridges; demo install → query →
uninstall → compose on a frozen 4B; each cartridge ships with a
verification contract (reference-contract, optical-design-laws L1).
All infra exists (writeback_compile, ternarize_factors, plate_linker).
Uniquely demonstrable: clean UNINSTALL (restore bit-exact). The most
spin-off-shaped item; makes the research program legible to outsiders.
Pairs with #1: redelivery makes installed cartridges actually *act*.

### 3. Quant-lint (quantization certificate)

Stethoscope pre/post-quant → "routing register preserved / degraded"
report per release. P-CRYSTAL-SURVIVAL (queued) is its validation; AYOT
(external, Intel ScaleQ) is precedent that calibration choice decides
low-bit survival. The GGUF ecosystem has no such gate. Includes the
own-beam calibration recipe as the constructive half: calibrate PTQ on
the model's own CoT, not generic text.

## Tier 2 — grounded designs, modest builds

### 4. Delivery-optimized RAG

Retrieval should deliver *licensing statements*, not passages: retrieve →
compile to classificatory subject-predicate form → pin in context. We
measured which register RAG should write to; standard pipelines ship the
wrong one. Cheap A/B: same retrieved content, passage-form vs
statement-form, licensing metric as the readout.

### 5. Typed context manager for agents

Context ≡ the typed operand stack (M4 corollary). Agent runtime maintains
a pinned "type header" — the membership facts that must keep licensing —
refreshed as the window slides. Prompt engineering with a law behind it.
Testable with the L(w) metric on long-context agent traces.

### 6. Model fingerprinting / lineage detection

The type register splits on *training regime*, not architecture (all-Qwen3
+ OLMo + Gemma vs the entire Pythia ladder). Stethoscope as provenance
instrument: distillation lineage, contamination, family identification
from activations alone. Research-adjacent product; the sweep already
demonstrated the discrimination.

### 7. Finetune telemetry (train by register, not by loss)

Sign-commitment result: confident routing core freezes by step ~5;
marginal band churns loss-neutrally forever; loss is done long before the
clock. A training monitor reporting routing-committed / still-deciding
per band, with evidence-gated stopping. The corridor's stop rule,
productized. Calibrates M8/TD-v2 on the way.

## Tier 3 — ambitious

### 8. Auditable model updates (compliance story)

Routing edits are discrete, loggable, ~600 KB, diffable. "Every behavior
change in this deployment is an inspectable, revertible commit" — a
property no current vendor offers. M5 (delta-log) + M8 (evidence-gated
commits) as an enterprise deployment discipline.

### 9. Agent halt-monitor

Read the halt/fire poles before generation → predict tool-call vs answer,
detect stuck-redex states in agent loops. P-HALT-POLE (queued) is the
validation probe. Runtime safety instrument for agentic deployments.

Not a product — the point. Everything above is scaffolding that de-risks
and funds it. See the-verbum-machine.md.
